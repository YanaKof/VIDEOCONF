# Раздел 6. Приложения

В данном разделе собраны вспомогательные материалы, крупноформатные таблицы и графики, которые дополняют текст курсовой работы.

## Перечень приложений

*   **Приложение А.** Исходные данные и расчет PEST-анализа макросреды рынка ВКС.
*   **Приложение Б.** Матрица SWOT-анализа для крупного вендора (IVA Technologies).
*   **Приложение В.** Расчет пяти сил Портера (лепестковая диаграмма и схема).
*   **Приложение Г.** Карта конкурентов рынка по методологии Magic Quadrant (базовые веса и сдвиг весов).
*   **Приложение Д.** Кривая зрелости технологий Hype Cycle для рынка корпоративных коммуникаций.
*   **Приложение Е.** Полный реестр из 20 источников информации с методиками расчета.
