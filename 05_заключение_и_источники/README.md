# Раздел 5. Заключение и список источников

## Заключение

В ходе выполнения курсовой работы был проведен комплексный анализ российского рынка видеоконференцсвязи (ВКС) и корпоративных коммуникаций, а также исследован сквозной путь данных и роль искусственного интеллекта.

По итогам работы можно сделать следующие выводы:
1. **Рынок находится на стадии активного роста**, вызванного форсированным импортозамещением после ухода зарубежных вендоров. Объем рынка ВКС оценивается в 23 млрд руб. с темпом роста 40% в год.
2. **Конкуренция является самой сильной силой Портера (5 из 5)**. Освободившиеся ниши делят между собой крупные экосистемы (МТС, VK, Яндекс) и специализированные лидеры (IVA, TrueConf). Барьеры для входа новых игроков крайне высоки из-за требований ФСТЭК и Реестра ПО.
3. **Технологическая платформа ВКС имеет высокую стоимость переключения** (от 1.5 до 3 млн руб.). Наибольшая зависимость наблюдается от слоя платформенного ПО (ОС и СУБД).
4. **ИИ внедряется на этапе аналитики** (Speech-to-Text, саммаризация встреч). Однако массовое внедрение ИИ-ассистентов сдерживается барьерами информационной безопасности (заказчикам нужен локальный On-Premise инференс).
5. **Ключевыми драйверами роста до 2028 года** станут переход на гибридные облака (Private Cloud) и глубокая интеграция генеративного ИИ в бизнес-процессы.

**Практическая значимость** работы заключается в том, что сформулированные рекомендации (оптимизация ПО под отечественные процессоры, развитие On-Premise ИИ-моделей) могут быть использованы российскими вендорами для удержания лидерских позиций.
